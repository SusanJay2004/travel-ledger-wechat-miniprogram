# 同行账本

同行账本是一款面向朋友出行、班级活动和小型团建的微信小程序，提供行程记账、多人协作与人民币 AA 分账。

项目当前处于开发阶段。产品范围、发布门禁和验收标准见 [最终开发计划.md](./最终开发计划.md)。

## 开发原则

- 金额统一以整数分存储和计算，避免浮点误差。
- `solo` 与 `collaboration` 双模式同时约束前端入口和云端权限。
- 共享数据只能经云函数鉴权写入，客户端不得直接修改权威集合。
- 仓库不保存 AppID 私有配置、云环境 ID、上传密钥或真实用户数据。

## 目录规划

```text
miniprogram/       微信小程序前端
cloudfunctions/    云函数
packages/domain/   领域模型、校验和结算算法
docs/              架构、合规和运维文档
```
