## 自动化基线

当前应执行：

```powershell
npm ci
npm run check
npm run build
npm run cloud:smoke-packages
npm audit --audit-level=critical
```

## 真实环境与发布阻断

1. 公开 MIT 仓库已创建并推送至 `https://github.com/SusanJay2004/travel-ledger-wechat-miniprogram`；Actions `29571833182` 与升级到 SHA 锁定 v7 后的 `29572128806` 均于 2026-07-17 通过。GitHub CLI 使用操作系统凭据库中的用户会话，令牌未写入仓库；后续推送继续以 Actions 通过为门禁。
2. 微信开发者工具已安装但 GUI 尚未首次扫码初始化；当前项目使用 `touristappid`，不存在本机私有 AppID 配置。
3. 需要用户本人注册/确认小程序主体、真实 AppID、开发云环境和服务类目；协作版必须取得平台允许或合规主体。
4. 需创建集合、唯一/组合索引与安全规则，部署 `api`、`avatar-review`、`maintenance`、`backup`，配置 `wxa_media_check` 消息推送后执行全部烟测。
5. 需至少一台 iOS、一台 Android 和三个独立微信账号完成主流程、弱网、同步和并发验收。
6. 需 5–10 个经同意的小团队灰度，完成正式隐私文本、备案、名称/图标/简介、审核、发布与搜索验证。
7. 需在生产配置监控和预算告警，实际演练备份恢复、回滚、投影修复和注销。

以上任一发布阻断未完成时，长期 goal 必须保持 active。
