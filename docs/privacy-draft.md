# 隐私与用户协议发布清单

小程序内已提供开发阶段的隐私保护指引和用户协议草案，但它们不能直接作为正式发布文本。

提交审核前必须补齐并由运营者本人确认：

- 真实运营主体姓名或名称、有效联系方式、投诉与个人信息请求渠道。
- 隐私指引和用户协议的版本号、生效日期、变更通知方式与争议解决条款。
- 微信公众平台后台“用户隐私保护指引”中实际使用的接口、数据类型、用途和保存期限。
- `OpenID`、用户资料、头像、好友、行程、账单、通知、同步信号、审计日志和云存储文件的逐项说明。
- 账号注销处理、共享账务匿名化、30 天恢复期、180 天高风险脱敏审计的合法性和准确表述。
- 云开发服务商及其他必要第三方处理者信息；若没有其他第三方，不得虚构。

当前应用不会读取通讯录、不会收集手机号、不会提供微信支付或代收款。若未来新增任何能力，必须先更新隐私说明和平台申报，再上线代码。
