# 微信小程序后台与审核文案

更新日期：2026-07-17。以下内容用于提交前复制和核对，不代表平台已经批准名称、类目或功能。

## 基础资料

- 名称首选：同行账本
- 名称备选：同行旅行账本、旅途同行账本
- 简短介绍（29 字）：按日期记录旅途支出，自动计算清晰准确的 AA 分账建议
- 功能介绍：同行账本用于个人旅行和集体出行记账。用户可按行程和日期记录事件、金额、参与份额与付款人，系统使用人民币整数分计算并给出最少转账笔数的分账建议。应用不代收资金、不发起支付，也不读取通讯录。
- 服务类目候选：工具—记账；最终必须以提交时微信公众平台对主体开放的类目为准。
- 搜索关键词候选：旅行记账、AA 分账、多人记账、行程账本、旅游账单
- 应用头像：`assets/brand/app-icon.png`（1024×1024）；后台上传后检查圆形和圆角裁切。

关键词必须真实对应已开放功能。若首发为 `solo`，不要提交“多人记账”关键词，避免审核文案与构建不一致。

## `solo` 首发审核说明

> 本版本为个人旅行记账工具。用户经微信身份进入后，可创建行程、添加日期和账单、设置参与份额与付款人、计算人民币 AA 分账建议、完结并在 30 天内恢复个人归档。消息页明确说明当前为单人模式；好友、邀请和多人同步入口在前端隐藏，云端也通过 `PRODUCT_MODE=solo` 禁止调用。本小程序不代收资金、不发起转账、不读取通讯录，也不提供用户私聊。

审核演示路径：

1. 首次进入：`pages/welcome/index`，阅读隐私说明并点击“微信身份进入”。
2. 首页：点击右上角“＋”，创建“审核演示行程”。
3. 详情：添加当天日期，再点击“记一笔”。
4. 账单：填写事件和消费金额，保存默认参与人与付款人。
5. 详情：点击“计算分账”，查看纳入金额、忽略账单和账本版本。
6. 生命周期：点击“完结行程”，再移入“我的—已完结行程”，可演示 30 天恢复。
7. 资料与权利：进入“我的—设置与隐私”，可查看隐私保护指引、用户协议、退出登录和注销账号。

## `collaboration` 审核说明

只有主体/类目书面确认允许后才可使用本段并部署 `PRODUCT_MODE=collaboration`。

> 本版本在个人记账基础上支持好友申请、行程邀请和多人同步记账。用户只能通过精确公开 ID 或不透明小程序码发送好友申请；对方明确同意后才建立好友关系。行程邀请也必须由对方确认。成员写入经过云函数鉴权、幂等和版本条件控制；冲突时客户端刷新权威数据，不静默覆盖。消息页只承载系统通知和好友管理，不提供文字、语音或图片私聊。本小程序不读取通讯录、不代收资金、不发起转账。

协作审核至少准备三个独立微信账号，并向审核人员说明如何取得好友关系和邀请通知。不要提交真实用户账单；只使用虚构演示数据。
