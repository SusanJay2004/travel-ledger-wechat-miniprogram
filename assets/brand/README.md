# 同行账本品牌素材

本目录保存可维护的 SVG 源文件和微信公众平台可用的 1024×1024 应用头像 PNG。

- `app-icon.svg` / `app-icon.png`：应用头像，视觉含义为“旅行地图 + 共享账本”。
- `tab-*.svg`：小程序底栏图标源文件；运行时 PNG 位于 `miniprogram/assets/tabbar/`。

颜色与小程序设计令牌保持一致：松石绿 `#0F6E65`、暖白 `#FFFCF6`、琥珀色 `#E6A15A`。源图标不包含文字，在圆形或圆角平台裁切下仍保留足够安全边距。

如修改 SVG，可使用 Chromium/Edge 的透明背景无头截图重新导出底栏图标；导出结果必须逐个验证为 81×81 RGBA PNG。正式上传前仍需在微信公众平台预览应用头像的圆形和圆角裁切效果。
